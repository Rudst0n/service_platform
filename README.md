# 🚀 ServHub SaaS

Sistema SaaS desenvolvido com Flask para gestão de empresas prestadoras de serviço.

## 📌 Objetivo

Criar uma plataforma simples, eficiente e escalável para empresas gerenciarem:

- clientes
- usuários
- serviços
- operações do dia a dia

Foco principal:

👉 produtividade  
👉 organização  
👉 facilidade de uso (mobile-first)  

---

## 🧠 Visão do Produto

O ServHub é um SaaS pensado para pequenos e médios prestadores de serviço, como:

- barbearias
- técnicos
- prestadores autônomos
- equipes operacionais

A ideia é sair de planilhas e WhatsApp e centralizar tudo em um sistema simples.

## ✅ Funcionalidades já implementadas

### 🔐 Autenticação
- login
- logout
- registro de empresa + usuário admin

### 🏢 Empresa
- criação automática no cadastro
- vínculo com usuários

### 👥 Usuários
- criação de usuários
- edição
- perfis:
  - admin_empresa
  - funcionario
  - visualizador
- reset de senha
- ativar/inativar usuário
- proteção contra auto-inativação

### 👤 Clientes
- cadastro
- edição
- exclusão
- busca por nome

### 🎨 Interface
- layout mobile-first
- sidebar no desktop
- navegação inferior no mobile
- feedback com alerts

## 🚧 MVP (Minimum Viable Product)

### 🎯 Objetivo do MVP

Entregar um sistema funcional que permita:

- cadastro de empresa
- gestão de usuários
- gestão de clientes
- cadastro de serviços
- controle básico de operação
